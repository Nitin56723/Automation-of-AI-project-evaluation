# Sentiment Analyzer Demo
## Goal
A simple rule-based sentiment analysis tool that classifies text as positive, negative, or neutral.

## How to Run
python main.py

## Input Type
Text string via stdin

## Expected Output
A single label: positive, negative, or neutral

## Sample Input
I love this product!

## Sample Output
positive

## Dependencies
- No external dependencies required

## Python Version
3.8+
